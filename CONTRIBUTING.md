# Contributing to EthioPay Hub

Thank you for your interest in contributing to EthioPay Hub! This document provides guidelines for contributing to the project.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. Please be respectful and inclusive.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/ethiopay-hub.git`
3. Create a feature branch: `git checkout -b feature/ethiopay-hub-feature-name`
4. Make your changes
5. Run quality checks: `yarn validate`
6. Commit with conventional commits
7. Push to your fork
8. Open a Pull Request

## Branch Naming Convention

- Features: `feature/{scope}-{description}`
- Bug Fixes: `fix/{issue-number}-{description}`
- Releases: `release/v{major.minor.patch}`
- Hotfixes: `hotfix/{issue-number}-{description}`
